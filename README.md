🟢 How to enable Green Screen of Death (GSOD)
To see the Green Screen instead of the standard Blue Screen (BSOD) when running this script, you must be part of the Windows Insider Program. 

Step-by-Step Guide:

Open Settings: Click the Start menu and go to Settings (or press Win + I). 


Update & Security: Navigate to Windows Update (on Windows 11, it is at the bottom of the left sidebar). 


Windows Insider Program: Look for the Windows Insider Program tab at the bottom. 


Get Started: Click the Get started button. 


Link your Account: You will need to sign in with a Microsoft Account to join. 


Choose your Channel: To guarantee the GSOD, select the Dev Channel or Canary Channel. 


Update & Restart: Go back to Windows Update, click Check for updates, and install the Insider Preview build. 


⚠️ Warning: Only use this script on test machines (like a secondary laptop or VMware). Running GsodCreator will immediately crash your system to show the green screen.
